# SecureShop Deployment Guide for Kali Linux

## Step 1: Install and Configure Apache & MariaDB

```bash
# Update system
sudo apt update && sudo apt upgrade -y

# Install Apache web server
sudo apt install apache2 -y

# Install MariaDB server
sudo apt install mariadb-server -y

# Install PHP and required modules
sudo apt install php php-mysql php-mysqli libapache2-mod-php -y

# Start and enable services
sudo systemctl start apache2
sudo systemctl enable apache2
sudo systemctl start mariadb
sudo systemctl enable mariadb

# Check service status
sudo systemctl status apache2
sudo systemctl status mariadb
```

## Step 6: Configure Apache

```bash
# Enable PHP module (if not already enabled)
sudo a2enmod php8.4

# Create a basic virtual host (optional)
sudo nano /etc/apache2/sites-available/secureshop.conf
```

Add this configuration:
```apache
<VirtualHost *:80>
    ServerName secureshop.local
    DocumentRoot /var/www/html
    
    # Intentionally weak security for the project
    <Directory /var/www/html>
        Options Indexes FollowSymLinks
        AllowOverride All
        Require all granted
    </Directory>
    
    # Enable error logging
    ErrorLog ${APACHE_LOG_DIR}/secureshop_error.log
    CustomLog ${APACHE_LOG_DIR}/secureshop_access.log combined
</VirtualHost>
```

```bash
# Enable the site
sudo a2ensite secureshop.conf

# Restart Apache
sudo systemctl restart apache2
```

## Step 9: Configure Logging for Splunk

```bash
# Ensure Apache logs are being written
sudo tail -f /var/log/apache2/access.log
sudo tail -f /var/log/apache2/error.log

# Make logs readable for Splunk
sudo chmod 644 /var/log/apache2/access.log
sudo chmod 644 /var/log/apache2/error.log

# Optional: Create custom log format for better Splunk parsing
sudo nano /etc/apache2/apache2.conf
```

Add this line to apache2.conf:
```apache
LogFormat "%h %l %u %t \"%r\" %>s %O \"%{Referer}i\" \"%{User-Agent}i\" %D" combined_with_time
```
